  SmartCook – Semantic Recipe Recommendation System (RAG + Graph + LLM)

Finding recipes using only the ingredients we have at home is often **limited and literal**: traditional systems rely solely on keyword search.  

**SmartCook** solves this with **semantic search**, allowing users to describe their ingredients in natural language and receive **relevant, well-explained recommendations**, just like a human chef would.

Technical Pipeline

1. **PostgreSQL**  
   - Relational database of recipes (ingredients, calories, cuisine type)  
   - Single source of truth for structured data  

2. **Sentence Transformers**  
   - Generates embeddings for recipes  
   - Normalized for similarity search (cosine similarity)  

3. **Neo4j**  
   - Stores embeddings as nodes in the graph  
   - Enables **efficient vector search** directly within the graph  

4. **RAG (Retrieval-Augmented Generation)**  
   - Retrieves semantically similar recipes  
   - Injects real context into the prompt before LLM generation  

5. **Gemini (LLM)**  
   - Recommends the best recipe based on the user’s ingredients  
   - Explains the reasoning behind the recommendation  
   - Suggests personalized variations
  
Python - Neo4j - PostgreSQL - Sentence TRansformers - Gemini API - RAG - SQLalchemy
